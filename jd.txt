Job Title: Python AI & Data Science Trainee
Department: Artificial Intelligence & Engineering
Location: Kochi, Kerala, India (Hybrid / On-site)
Engagement: Full-Time Trainee / Internship (6 Months leading to Full-Time Role)

Role Overview:
We are seeking an enthusiastic, hands-on Python AI & Data Science Trainee to join our core product engineering team. You will assist in developing production-grade GenAI pipelines, document intelligence engines, automated data processing workflows, and backend microservices. This role demands strong foundational Python programming, an understanding of applied machine learning, practical familiarity with LLMs/APIs, and a commitment to writing clean, maintainable code.

Key Responsibilities:
- Design and implement Python scripts to ingest, parse, clean, and structure unstructured documents (PDFs, Word documents, JSON, HTML).
- Build LLM-powered features using modern APIs (OpenRouter, OpenAI, HuggingFace) and local inference runtimes (e.g., Ollama).
- Implement token-efficient prompt engineering, retrieval-augmented generation (RAG) components, and embeddings-based semantic search.
- Write modular, unit-tested, and PEP 8-compliant code adhering to strict linting and code quality standards.
- Assist in developing backend data endpoints using lightweight web frameworks (FastAPI or Django/HTMX).
- Benchmark model performance, latency, token consumption, and output structured validation (Pydantic / JSON Schema).

Required Technical Skills:
- Core Python: Proficient in Python 3.10+, data structures, OOP concepts, file I/O, error handling, and type hinting.
- Data Processing & Manipulation: Hands-on experience with Pandas, NumPy, and Regular Expressions (re).
- Document Parsing: Familiarity with libraries such as pypdf, pdfplumber, PyMuPDF (fitz), or python-docx.
- AI & LLM Foundations: Understanding of prompt engineering, temperature/top-p parameters, embeddings, cosine similarity, and vector indexing.
- API Integration: Experience with REST APIs, the `requests` library, or SDK integrations with rate-limiting and retry logic.
- Developer Tools: Git/GitHub, virtual environments (venv), and Linux/Unix CLI familiarity.

Desirable / Bonus Skills:
- Experience with Vector Databases (ChromaDB, FAISS, Qdrant) or semantic search pipelines.
- Knowledge of structured LLM outputs using Instructor, Pydantic, or native JSON Schema mode.
- Prior open-source contributions, competitive programming exposure, or end-to-end deployed AI/Data pet projects.
- Familiarity with code linters and formatters (Pylint, Black, Flake8).

Academic & Eligibility Criteria:
- Bachelor's or Master's degree in Computer Science, Data Science, Artificial Intelligence, Mathematics, Information Technology, or related quantitative disciplines.
- Graduating batch of 2024, 2025, or 2026 (Freshers and final-year students eligible).
